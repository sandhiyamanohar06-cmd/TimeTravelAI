# 🌀 TimeShift AI

## AI-Powered Counterfactual Timeline & Paradox Simulator

TimeShift AI is an AI-powered web application that explores alternate-history scenarios.

The user changes a historical event, and the AI generates a possible alternate timeline with future consequences and paradox analysis.

## 🚀 Features

- Generate alternate historical timelines
- Show key years and major changes
- Analyze technology, economy, and society
- Detect possible timeline paradoxes
- Generate a Paradox Score from 0–100
- Simple futuristic web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- OpenAI API
- HTML/CSS
- python-dotenv
